# Project instructions

- This repository is an isolated browser-extension project. Do not read credentials, personal browser data, global user instructions, or sibling projects.
- Keep all work local. Do not create remotes, push commits, or publish to an extension store.

## Agent skills

### Issue tracker

Issues are tracked as Local Markdown under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The tracker uses the five default Matt Pocock triage roles. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. Read `CONTEXT.md` and relevant ADRs before implementation. See `docs/agents/domain.md`.
