# 外链直达 0.1 本地规格

**Status:** ready-for-agent

## Problem Statement

用户在掘金、知乎和 CSDN 阅读内容并点击站外链接时，会停在平台自己的“即将离开/继续访问”中转页，需要重复确认。用户希望对已经明确识别的中转地址无感直达，同时不降低浏览器或业务网站本身的安全确认。

## Solution

提供一个中文 Chrome Manifest V3 扩展“外链直达”。它在支持的来源页把明确可还原的中转链接改为真实目的地址，并在用户实际进入支持的中转页时自动跳转。工具栏弹窗提供总开关和掘金、知乎、CSDN 分站开关，设置仅保存在本机。

## User Stories

1. 作为掘金读者，我希望点击已核实的掘金外链时直接到目的地址，从而免去二次确认。
2. 作为知乎读者，我希望点击已核实的知乎外链时直接到目的地址，从而免去二次确认。
3. 作为 CSDN 读者，我希望点击已核实的 CSDN 外链时直接到目的地址，从而免去二次确认。
4. 作为用户，我希望即使直接打开支持的中转地址也能自动跳转，从而覆盖来源页未提前改写的情况。
5. 作为用户，我希望能用总开关暂停全部处理，并在关闭重开弹窗后仍保留选择。
6. 作为用户，我希望能单独关闭任一平台，并让其他平台继续工作。
7. 作为安全敏感用户，我希望恶意协议、无效目标、同地址循环、未知参数及过深嵌套保持平台原行为。
8. 作为隐私敏感用户，我希望插件不上传浏览历史或网页内容。
9. 作为动态网页用户，我希望稍后插入的支持链接也能被处理，且页面不会因全量反复扫描而卡顿。
10. 作为本地安装用户，我希望看到简洁中文状态说明和实际站点范围。

## Implementation Decisions

- 采用 WXT、Vanilla TypeScript 和 Manifest V3，使用工具栏弹窗、来源页内容脚本和中转页内容脚本。
- 站点适配器以精确主机、精确目的参数和来源域集合表达；不使用全网通配重写。
- 共享解析器返回“已支持且安全的目的地址”或“保留原行为”，并以最多三层、最大 8192 字符及 seen-set 限制解码和嵌套。
- 有效目的地址必须是绝对 `http:` 或 `https:` URL，且不得携带用户名或密码。
- 中转页在 `document_start` 查询本地设置并使用替换式导航，避免污染返回历史。
- 来源页初始处理现有锚点，并用 MutationObserver 只处理新增子树；保留链接的 target、rel、文字和事件语义。
- 设置模型包含总开关及三个分站布尔值，缺省全部开启；存于 `chrome.storage.local`，无远程请求或分析代码。
- 权限仅包括 `storage` 和明确列出的来源/中转 HTTPS 主机。
- 技术默认、测试缝、Local Markdown 发布与票拆分均按本轮用户授权由编排决定。

## Testing Decisions

- 纯函数公开接口是安全解析和来源链接决策的测试缝，用已知字面量 fixtures 覆盖成功、合法编码、嵌套、无效参数、恶意协议、凭据、循环、超长及开关。
- popup 的真实 action 入口是设置持久化测试缝：用户操作开关，关闭再打开并核对状态。
- 三个实际中转 URL 是浏览器集成测试缝：加载真实构建、访问中转地址并核对最终 URL；站点公开限制如实保存。
- 来源页尽量使用公开真实页面观察链接改写；无法稳定访问时，纯函数 fixture 只证明解析边界，不冒充来源页 E2E。
- 每票固定 Git 基线，执行 Standards 与 Spec 两个独立审查；最终候选另做整合审查。

## Acceptance Criteria

- AC-01：当前构建可作为已解压扩展安装，ID、版本和路径可记录，并能从工具栏 action 打开弹窗。
- AC-02：总开关和三个分站开关可操作，并在关闭重开 action 后保持。
- AC-03：掘金的已核实中转地址自动到达预期 HTTP(S) 目的地址；关闭掘金或总开关时保留中转行为。
- AC-04：知乎的已核实中转地址自动到达预期 HTTP(S) 目的地址；若公开站点拦截先于扩展执行，保存真实限制且不伪造。
- AC-05：CSDN 的已核实中转地址自动到达预期 HTTP(S) 目的地址；关闭 CSDN 时保留中转行为。
- AC-06：无效参数、未知参数、恶意协议、凭据、循环、过深或超长输入不跳转。
- AC-07：来源链接决策 fixture 覆盖现有与动态链接及各开关，不宽泛处理未知主机。
- AC-08：最终 `extension/` 与候选指纹一致，release bundle 静态检查和真实验收门禁均通过。

## Out of Scope

- 绕过 Chrome TLS、恶意网站、安全浏览警告或任何登录、支付、权限确认。
- 支持未核实平台、任意重定向服务、短链展开、远程规则或云同步。
- Chrome Web Store 发布、远端仓库、遥测、历史记录上传。

## Further Notes

知乎当前公开地址在独立受控 Chrome 中可能触发站点 566 防护；这属于外部站点限制，最终报告会区分“扩展代码路径”和“公开站点可达性”。
