# Issue tracker: Local Markdown

Issues and specs for this repository live as Markdown files under `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`.
- The published specification is `.scratch/<feature-slug>/spec.md`.
- Each implementation issue is a separate `.scratch/<feature-slug>/issues/<NN>-<slug>.md` file.
- `Status:` records triage or implementation state.
- `Blocked by:` lists prerequisite ticket numbers, or `None`.
- Review and acceptance evidence is appended to the issue before it is closed.

Publishing a local issue means writing its file. No GitHub, remote, or network tracker is used.
