# Triage labels

| Role | Local label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs maintainer evaluation |
| `needs-info` | `needs-info` | Waiting for missing reporter information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and implementable |
| `ready-for-human` | `ready-for-human` | Requires a human-only action |
| `wontfix` | `wontfix` | Will not be implemented |
